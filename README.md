# My Todo List

A simple React application built using Vite to practice component structure, state cleanup, and rendering lists.

## Features

- Displays a custom application title.
- Renders an initial list of todos dynamically using JavaScript `map()`.

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## Installation Instructions

1. Clone the repository:
   ```
   git clone https://github.com/codewhizzz/todo-list.git
   ```
2. Navigate into the project directory:

cd <todo-list>

3. Install the dependencies:
   npm install

How to Run the Development Server

    Start the development server:

    npm run dev

    Open your browser and navigate to the local URL provided in the terminal (usually http://localhost:5173).
